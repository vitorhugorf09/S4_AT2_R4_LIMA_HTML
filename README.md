# Sport Mais - Catálogo de Produtos Esportivos

Projeto desenvolvido utilizando HTML e CSS para apresentar um catálogo de uma loja de artigos esportivos.

## Funcionalidades

- Listas de categorias e subcategorias.
- Listas numeradas e de definição.
- Tabelas com informações dos produtos.
- Mesclagem de células com colspan e rowspan.
- Estilização com cores, bordas e espaçamentos.

## Tecnologias utilizadas

- HTML5
- CSS3

## Como executar

1. Baixe os arquivos do projeto.
2. Deixe o `index.html` e o `style.css` na mesma pasta.
3. Abra o arquivo `index.html` no navegador.

## Objetivo

Praticar o uso de listas e tabelas em HTML, além de aprender a organizar e estilizar informações em uma página web.
